# Manim Audio Generation Pipeline

This set of tools helps you generate high-quality voiceover narration for your Manim animations. The pipeline analyzes your Manim code, generates an appropriate narration script, converts it to speech, and combines it with your video.

## Pipeline Overview

The audio generation pipeline consists of 4 steps:

1. **Script Generation**: Analyzes your Manim code to identify animation segments and generates appropriate narration.
2. **TTS Audio Generation**: Converts each segment of the script to high-quality speech using OpenAI's TTS API.
3. **Audio Combination**: Combines audio segments with appropriate timing and pauses to match the animation.
4. **Audio-Video Combination**: Adds the combined audio to your Manim animation video.

## Prerequisites

- Python 3.7+
- OpenAI API key set as an environment variable (`OPENAI_API_KEY`)
- FFmpeg installed on your system (for audio-video combination)
- Required Python packages: `openai`, `pydub`, `numpy`

## Quick Start

The simplest way to use the pipeline is with the all-in-one script:

```bash
python generate_audio_for_video.py path/to/your/manim_file.py
```

This will:
1. Analyze your Manim code and generate a narration script
2. Convert the script to speech using OpenAI's TTS API
3. Combine the audio segments with appropriate timing
4. Add the audio to your most recent rendered video of this scene

## Individual Components

You can also run each step individually:

### 1. Generate Narration Script

```bash
python voice_script_generator.py path/to/your/manim_file.py [--viz-plan path/to/visualization_plan.json] [--output output_script.json]
```

This analyzes your Manim code, identifies animation segments, and generates appropriate narration text for each segment.

### 2. Generate TTS Audio

```bash
python generate_tts_from_script.py path/to/script.json [--output-dir tts_output/your_scene]
```

This generates TTS audio for each segment in the script using OpenAI's TTS API with the Onyx voice.

### 3. Combine Audio Segments

```bash
python combine_audio_segments.py tts_output/your_scene [--output path/to/output.mp3] [--timing path/to/timing_info.json]
```

This combines the audio segments with appropriate timing and pauses to match the animation.

### 4. Add Audio to Video

```bash
python add_audio_to_video_from_file.py path/to/audio.mp3 [--video path/to/video.mp4] [--output path/to/output.mp4]
```

This adds the audio to your Manim animation video using FFmpeg.

## Advanced Usage

### Visualization Plan Integration

For more context-aware narration, you can provide a visualization plan JSON file (generated by the idea generation tools):

```bash
python generate_audio_for_video.py path/to/your/manim_file.py --viz-plan path/to/visualization_plan.json
```

### Custom Output Directories

You can specify custom output directories for the audio files:

```bash
python generate_audio_for_video.py path/to/your/manim_file.py --output-dir custom/output/dir
```

### Specific Video File

If you want to add audio to a specific video file (instead of the most recent one):

```bash
python generate_audio_for_video.py path/to/your/manim_file.py --video-file path/to/specific_video.mp4
```

## Technical Details

### Script Format

The script is stored in JSON format with the following structure:

```json
{
  "scene_name": "YourSceneName",
  "total_duration": 30.5,
  "segments": [
    {
      "start_time": 0.0,
      "duration": 5.0,
      "description": "Introduction",
      "narration": "Welcome to this video about..."
    },
    ...
  ]
}
```

### Audio Timing

The audio timing system attempts to synchronize the narration with the animation by:

1. Analyzing the Manim code to estimate the timing of each animation segment
2. Generating audio with appropriate length for each segment
3. Adding silence between segments to match the animation timing

### Voice Customization

The system uses OpenAI's TTS API with the "onyx" voice by default. To customize the voice, modify the `generate_tts_from_script.py` file.

## Troubleshooting

### Audio Not Syncing with Video

If the audio doesn't sync well with the video:

1. Check the timing information in `timing_info.json`
2. Adjust the narration text to be shorter or longer as needed
3. Add explicit timing comments in your Manim code (e.g., `# This is important (3.0s)`)

### Missing API Key

If you see an error about the missing API key:

```bash
export OPENAI_API_KEY="your-api-key-here"
```

### FFmpeg Not Found

Make sure FFmpeg is installed and in your PATH:

```bash
# macOS
brew install ffmpeg

# Ubuntu
sudo apt-get install ffmpeg

# Windows
# Download from https://ffmpeg.org/download.html
```
